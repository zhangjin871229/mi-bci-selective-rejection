# Reliability scores for MI-BCI rejection compared under a frozen analysis protocol — code and materials

Code, frozen protocol files with checksums, the amendment and deviation records, trial-level outputs and figure
scripts for the revised manuscript submitted to *Biomedical Signal Processing and Control*.

The directory layout mirrors the original working tree, because the scripts locate data and outputs by relative
paths (`revision/rv/common.py`, `revision/bci2b/rv2b/common2b.py`). The folder names `交付` ("delivery", the
original code package) and `BCI返修` ("revision", manuscript working folder) are kept unchanged for that reason.

Download the public data sets and place them as follows:

```

true_labels/        A01T.mat … A09E.mat     https://www.bbci.de/competition/iv/results/ds2a/true_labels.zip
BCICIV_2b_bnci/     B01T.mat … B09E.mat     BNCI Horizon 2020, data set 004-2014 (http://bnci-horizon-2020.eu/database/data-sets)
```

`true_labels/PROVENANCE.md` and Supplementary Table S1 list the MD5 checksums of the files used.

## Environment

Python 3.8.2 on Windows, CPU only. Install with `pip install -r requirements.txt`.

## Reproduction

BCI IV 2a (from `revision/rv/`):

```
python prep.py                 # epoch caches from raw GDF (cache/)
python train_subject.py A01    # repeat for A01–A09; 5-member ensemble, never reads evaluation labels
python perturb.py A01          # repeat for A01–A09; raw-EEG perturbations through frozen members
python report.py               # one-shot evaluation (clean + perturbations), statistics, tables, Figs. 2–3 (risk–coverage, reliability)
python explore_fbcsp_gmm.py    # exploratory FBCSP-GMM analysis
python make_figures.py         # Fig. 1 (pipeline), Fig. 5 (perturbations)
python make_figures_v2.py      # Fig. 6 (representation dependence), Fig. 4 (confusion/rejection)
python make_supplement.py      # Supplementary tables S1–S9
```

`run_all.sh` runs training and perturbations for all participants. Training takes about 20–35 min per participant on CPU.

BCI IV 2b (from `revision/bci2b/rv2b/`): `prep2b.py`, then `train2b.py B01` … `B09`, then `eval2b.py`
(see `run_2b.sh`). `eval2b.py` is the only script that opens the 2b evaluation labels and refuses to run if
`protocol_2b.json` differs from its frozen checksum.

To check the protocol checksums:

```
sha256sum revision/protocol.json revision/bci2b/protocol_2b.json
# 49cdf03c68bf29ac62079592b500c38244f8db1a88a1377a10b6723b1f57ec4c  (2a, after amendment 1)
# 53a30bc842efb21423537c078150fedfc6566bf56fe391bb5637c5fc041df741  (2b)
```

Statistics, tables and figures can be regenerated without retraining from the included member outputs
(`out/raw/`): run `prep.py` (builds the epoch caches, which carry the labels), then `report.py`,
`explore_fbcsp_gmm.py`, the `make_*` scripts and `takeover_codex/verify_existing.py`. Use `report.py` rather than
`evaluate.py` alone, because the perturbation family (D) is added to `stats_clean.json` by `report.py`.
